# ADR-001. Elasticsearch для полнотекстового поиска каталога

**Статус:** принято

## Контекст

В каталоге около 40 тысяч электронных книг. Поиск SQL-запросом с `LIKE` по названию выполняется несколько секунд, не находит слова внутри текста PDF и EPUB и не учитывает морфологию русского языка. По запросу «программированию» книга «Основы программирования» не находится.

## Решение

Для поиска используется Elasticsearch с русским морфологическим анализатором. При загрузке книги из файла извлекается текст и вместе с метаданными добавляется в поисковый индекс. PostgreSQL остается основной базой для метаданных и выдачи, Elasticsearch отвечает только за поиск.

## Рассмотренная альтернатива

Встроенный полнотекстовый поиск PostgreSQL. Он проще, так как не требует отдельного сервиса, но на полных текстах книг хуже ранжирует результаты, не дает удобной подсветки фрагментов и нагружает основную базу, через которую идет выдача книг. Поэтому от него отказались.

## Последствия

Появляется отдельный сервис, который нужно разворачивать и сопровождать, а индекс нужно обновлять при загрузке и удалении книг.
